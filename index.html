Doors

AC-825IP door system

Reader ports set the limit, not doors. A door with a reader on each side (in/out) uses two reader ports.

Elevators

Elevator control (per elevator)

Each elevator needs its own AC-825IP. Its spare outputs can run doors, but that lowers the floor count. An R-805 handles 16 floors.
